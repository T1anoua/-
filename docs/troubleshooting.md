# 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 打不开网页 | 检查板卡供电与网口灯，电脑以太网地址及 `config.json`；执行 `ping 192.168.2.99`。 |
| 网页打开但无图 | 执行 `05_check.bat`；板端检查 `ls -l /dev/video*` 和 `journalctl -u ore-vision -n 50 --no-pager`。 |
| 摄像头已枚举但取流失败 | 关闭其他取流程序，只重插相机 USB，再检查驱动与服务日志。 |
| 一个框包住多块矿石 | 样品之间留出空隙；当前程序按外轮廓检测，不能可靠分开紧贴目标。 |
| 颜色名称不符合样品 | 检查照明、分割掩膜和名称映射。名称仅按颜色规则显示，不能据此鉴定矿物。 |
| 串口没数据 | 检查调试 USB 驱动、COM 号和 115200 波特率；不要让两个程序同时占用同一串口。 |
| 双击 BAT 失败 | 先完整解压，安装 Python 3.12，再运行 01_setup.bat。依赖安装需网络。 |
| 文件校验不通过 | 发布后的源码或配置被修改会改变校验值；核对修改内容或重新解压原包。 |

原板曾通过调整 USB0 PHY 的 MIO9 复位序列和 CMA 内存位置恢复取流。这属于特定板卡与镜像的启动配置，不是通用应用安装步骤。此源码包不修改启动分区；新板应根据厂商资料处理驱动与启动问题。

修改、调试前保存原配置。板端安装脚本会备份原应用和 service，失败时根据终端中的备份路径恢复。断电前正常关闭系统，避免 SD 卡文件系统损坏。
